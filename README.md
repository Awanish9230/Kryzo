# Kryzo - College Test Series Platform

Kryzo is a comprehensive test-series platform designed for colleges to help students prepare for technical interviews and competitive exams. It features diagnostic tests, adaptive weekly improvement plans, and custom test creation.

## 🚀 Features

- **Student Dashboard**: Track progress, attempt tests, and view improvement plans.
- **Admin Panel**: Manage questions (MCQ & Coding), create tests, and view analytics.
- **Diagnostic Tests**: Assess current skill level and get personalized recommendations.
- **Adaptive Learning**: Weekly plans based on weak areas.
- **Code Execution**: Built-in coding environment.

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT (JSON Web Tokens)

## 📂 Project Structure

- \`client/\`: Frontend React application
- \`server/\`: Backend Node.js API

## 🚦 Getting Started

### Prerequisites

- Node.js installed
- MongoDB installed or Atlas connection string

### Installation

1.  **Clone the repository**
    \`\`\`bash
    git clone <repo-url>
    cd Kryzo
    \`\`\`

2.  **Setup Backend**
    \`\`\`bash
    cd server
    npm install
    # Create .env file (see ADMIN_README.md for details)
    npm run dev
    \`\`\`

3.  **Setup Frontend**
    \`\`\`bash
    cd client
    npm install
    npm run dev
    \`\`\`
